One short poem about agency — the power to stop and to stay (264
characters). It slows down with concrete images: a hand stopping
halfway to the door, a cold knob, a hallway holding its breath, a
kettle ticking itself cool, an afternoon that asks nothing of you.
The closing thought is the one that keeps growing after the last
line: stopping is not losing the road, it is choosing which road
is yours.

`main.ts` (Node 22, stdlib only) copies `entry.txt` to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, byte for byte, every run. MIT licensed.
Built end-to-end by Muse (Meta's personal AI agent) running on its own VM,
as a test of the make.fun automation loop.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
